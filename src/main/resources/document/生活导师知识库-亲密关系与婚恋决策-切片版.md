# 生活导师知识库-亲密关系与婚恋决策（切片版）

## [LIFE-REL-001] 关系是否继续
META: doc_id=LIFE-REL; chunk_id=LIFE-REL-001; domain=intimacy; topic=关系去留; risk=high; source=亲密关系与婚恋决策
**适用范围**：关系去留决策。  
**结论**：看趋势与修复意愿，不只看一时情绪。  
**可执行步骤**：
1. 评估尊重/信任/沟通/目标兼容4项。
2. 设4-8周修复窗口。
3. 定义可验证修复动作。  
**风险提醒**：沉没成本不等于继续理由。  
**复盘问题**：这段关系让你长期更好还是更差？

## [LIFE-REL-002] 频繁争吵
META: doc_id=LIFE-REL; chunk_id=LIFE-REL-002; domain=intimacy; topic=冲突管理; risk=medium; source=亲密关系与婚恋决策
**适用范围**：高频冲突。  
**结论**：先修冲突规则，再谈具体事件。  
**可执行步骤**：
1. 约定“不辱骂/不翻旧账/不冷暴力”。
2. 每次冲突后做10分钟复盘。
3. 每周固定关系沟通时段。  
**风险提醒**：人格化指责会削弱修复空间。  
**复盘问题**：你们最容易在哪个环节升级？

## [LIFE-REL-003] 分手后恢复
META: doc_id=LIFE-REL; chunk_id=LIFE-REL-003; domain=intimacy; topic=分手恢复; risk=medium; source=亲密关系与婚恋决策
**适用范围**：失恋调整。  
**结论**：恢复核心是重建生活主轴。  
**可执行步骤**：
1. 暂停高触发行为（反复翻记录）。
2. 恢复作息与社交节律。
3. 制定30天恢复计划。  
**风险提醒**：报复性进入新关系会加重损耗。  
**复盘问题**：你从这段关系学到什么？

## [LIFE-REL-004] 异地关系维护
META: doc_id=LIFE-REL; chunk_id=LIFE-REL-004; domain=intimacy; topic=异地维护; risk=medium; source=亲密关系与婚恋决策
**适用范围**：异地恋/异地婚姻。  
**结论**：需要“固定连接机制”而不是随缘沟通。  
**可执行步骤**：
1. 每天短沟通+每周深聊。
2. 提前排定见面节奏。
3. 保持共同目标与共同项目。  
**风险提醒**：长期无计划见面会快速消耗信任。  
**复盘问题**：你们的连接机制是否可持续？
