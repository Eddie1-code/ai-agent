# 知域知识库-时间管理与拖延应对（切片版）

## [LIFE-TIME-001] 拖延严重
META: doc_id=LIFE-TIME; chunk_id=LIFE-TIME-001; domain=time; topic=拖延应对; risk=medium; source=时间管理与拖延应对
**适用范围**：任务反复延后。  
**结论**：用“2分钟启动”打断拖延循环。  
**可执行步骤**：
1. 每个任务定义2分钟起步动作。
2. 启动后进入25分钟专注。
3. 结束时写下下一次启动点。  
**风险提醒**：只做计划不做启动。  
**复盘问题**：哪个任务最容易被你回避？

## [LIFE-TIME-002] 忙但没成果
META: doc_id=LIFE-TIME; chunk_id=LIFE-TIME-002; domain=time; topic=高价值时间; risk=medium; source=时间管理与拖延应对
**适用范围**：低效忙碌。  
**结论**：先保护高价值时间块。  
**可执行步骤**：
1. 每天锁定90分钟关键任务时段。
2. 低价值事务集中批处理。
3. 关闭非必要通知。  
**风险提醒**：即时反馈任务会吞噬深度任务。  
**复盘问题**：今天你推进了哪个长期目标？

## [LIFE-TIME-003] 待办清单过载
META: doc_id=LIFE-TIME; chunk_id=LIFE-TIME-003; domain=time; topic=任务过载; risk=medium; source=时间管理与拖延应对
**适用范围**：清单焦虑。  
**结论**：清单要做减法，只保留本周可执行项。  
**可执行步骤**：
1. 每日最多3个重点任务。
2. 未完成项必须标注阻碍原因。
3. 每周删除低价值事项。  
**风险提醒**：任务堆积会制造无力感。  
**复盘问题**：你删掉了哪些“看似重要”的任务？

## [LIFE-TIME-004] 临时任务插队
META: doc_id=LIFE-TIME; chunk_id=LIFE-TIME-004; domain=time; topic=任务插队管理; risk=low; source=时间管理与拖延应对
**适用范围**：节奏被打断。  
**结论**：建立插队规则而不是来者不拒。  
**可执行步骤**：
1. 先判断紧急性与影响范围。
2. 只允许替换同等级任务。
3. 被替换任务必须重排时间。  
**风险提醒**：长期临时优先会导致主线失守。  
**复盘问题**：这件临时任务真的必须今天做吗？
