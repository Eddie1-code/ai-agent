# 生活导师知识库-目标设定与行动拆解（切片版）

## [LIFE-GOAL-001] 不知道从哪开始
META: doc_id=LIFE-GOAL; chunk_id=LIFE-GOAL-001; domain=goal; topic=起步困难; risk=low; source=目标设定与行动拆解
**适用范围**：目标模糊、迟迟不行动。  
**结论**：先做最小起步动作，比完美计划更重要。  
**可执行步骤**：
1. 只选1个14天目标。
2. 拆成每天20-40分钟动作。
3. 固定触发时段（如20:30）。
4. 前7天只看完成率。  
**风险提醒**：不要并行多个大目标。  
**复盘问题**：你今天能完成的最小动作是什么？

## [LIFE-GOAL-002] 目标太多
META: doc_id=LIFE-GOAL; chunk_id=LIFE-GOAL-002; domain=goal; topic=目标优先级; risk=low; source=目标设定与行动拆解
**适用范围**：优先级混乱。  
**结论**：按“影响力x可执行性”排序，只做前1-2项。  
**可执行步骤**：
1. 每个目标打1-5分。
2. 选最高分目标执行。
3. 其余放入等待池，每周复核。  
**风险提醒**：高紧急不等于高价值。  
**复盘问题**：你在做推进长期价值的事吗？

## [LIFE-GOAL-003] 总是坚持不下来
META: doc_id=LIFE-GOAL; chunk_id=LIFE-GOAL-003; domain=goal; topic=习惯坚持; risk=medium; source=目标设定与行动拆解
**适用范围**：三分钟热度。  
**结论**：坚持问题多是机制问题，不是性格问题。  
**可执行步骤**：
1. 把动作降到5分钟可完成。
2. 增加可见反馈（打卡/计数）。
3. 引入外部监督。  
**风险提醒**：连续中断2天要立即重启。  
**复盘问题**：你的中断触发点是什么？

## [LIFE-GOAL-004] 年目标如何落地
META: doc_id=LIFE-GOAL; chunk_id=LIFE-GOAL-004; domain=goal; topic=长期目标拆解; risk=low; source=目标设定与行动拆解
**适用范围**：长期目标拆解。  
**结论**：目标必须分层到季度、月、周、日。  
**可执行步骤**：
1. 年目标拆成4个季度里程碑。
2. 每月只设1个关键结果。
3. 每周安排3个核心任务。
4. 每天落地1个最关键动作。  
**风险提醒**：只做年度愿景不做周计划会失真。  
**复盘问题**：本周哪个任务最能推动季度结果？
