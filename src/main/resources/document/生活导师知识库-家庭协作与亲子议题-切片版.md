# 生活导师知识库-家庭协作与亲子议题（切片版）

## [LIFE-FAM-001] 家务分工失衡
META: doc_id=LIFE-FAM; chunk_id=LIFE-FAM-001; domain=family; topic=家务分工; risk=medium; source=家庭协作与亲子议题
**适用范围**：家庭责任不均。  
**结论**：先把隐形劳动显性化，再重分工。  
**可执行步骤**：
1. 列出全部家庭任务清单。
2. 按总量公平分配责任。
3. 每周复盘并调整。  
**风险提醒**：只谈情绪不谈机制难改善。  
**复盘问题**：哪类任务最耗能却最容易被忽视？

## [LIFE-FAM-002] 育儿观念冲突
META: doc_id=LIFE-FAM; chunk_id=LIFE-FAM-002; domain=family; topic=育儿冲突; risk=medium; source=家庭协作与亲子议题
**适用范围**：父母规则不一致。  
**结论**：先统一目标，再协商方法。  
**可执行步骤**：
1. 确定3条共同底线。
2. 争议方法试运行一周。
3. 对外口径保持一致。  
**风险提醒**：规则反复会强化孩子对抗。  
**复盘问题**：你们冲突的是价值还是方法？

## [LIFE-FAM-003] 代际沟通冲突
META: doc_id=LIFE-FAM; chunk_id=LIFE-FAM-003; domain=family; topic=代际沟通; risk=medium; source=家庭协作与亲子议题
**适用范围**：与父母/岳父母沟通紧张。  
**结论**：分层沟通，避开情绪峰值争论。  
**可执行步骤**：
1. 先表达理解，再提边界。
2. 重大议题提前预约沟通。
3. 由对应子女优先沟通本家事项。  
**风险提醒**：临场争辩通常只会升级。  
**复盘问题**：下一次你能提前做什么预防？

## [LIFE-FAM-004] 工作与育儿平衡
META: doc_id=LIFE-FAM; chunk_id=LIFE-FAM-004; domain=family; topic=工作育儿平衡; risk=medium; source=家庭协作与亲子议题
**适用范围**：角色冲突。  
**结论**：通过排班与备份机制降低冲突。  
**可执行步骤**：
1. 做家庭周排班（工作/育儿/休息）。
2. 关键时段设置备份照护方案。
3. 明确不可打断时段与可协商时段。  
**风险提醒**：长期单人扛全部容易崩盘。  
**复盘问题**：本周哪一段最需要备份支持？
